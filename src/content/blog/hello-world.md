This is a first post written in Markdown and committed directly to the repo.

The goal is simple: keep writing close to the code, let the build process pick up each post, and render everything in the existing site without adding a CMS.

## What works

- Frontmatter for title, date, description, and slug
- GitHub-flavored Markdown
- Code blocks
- Links and normal prose

```ts
const publish = (post: string) => commit(post)
```
